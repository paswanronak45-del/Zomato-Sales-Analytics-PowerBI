# 🍽️ Zomato Sales Analytics Dashboard
## 📌 Project Overview
This project analyzes Zomato sales data using SQL and Power BI to uncover business insights related to sales performance, customer behavior, restaurant performance, and payment trends.
---
## 🛠️ Tools Used
- Power BI
- PostgreSQL
- SQL
- Microsoft Excel
---
## 📂 Dataset
- 5,000 Orders
- Restaurant-wise Sales
- Food Categories
- Customer Ratings
- Delivery Information
- Payment Methods
---
## 📊 Dashboard KPIs
- Total Sales
- Total Orders
- Average Order Value
- Average Customer Rating
---
## 📈 Dashboard Visualizations
- Monthly Sales Trend
- Sales by Food Category
- Sales by City
- Sales by Payment Method
---
## 💻 SQL Analysis
- Total Revenue
- Completed Orders
- Highest Revenue Restaurant
- Average Order Value by City
- Average Delivery Time
- Customer Rating Analysis
- Maximum Discount
- Highest Order Value
